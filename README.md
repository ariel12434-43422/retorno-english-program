## הקמה ראשונה

> **בוצע (29.10.2026):** פרויקט Supabase בשם `retorno` (אירופה), מסד נתונים והרשאות, כתובות כניסה, שולח ההתראות `notify` והמפתח הסודי שלו, ופרסום האתר. השלבים למטה נשמרים לתיעוד ולהקמה מחדש. ההגדרות ב-GitHub (שלב 3) לא נדרשות – החיבור כתוב ב-`web/config.js`, והמפתח הציבורי מותר לחשיפה.

### 1. פרויקט ב-Supabase (מסד הנתונים)
1. נכנסים ל-[supabase.com](https://supabase.com) ונרשמים (חינם).
2. **New project** – שם: `retorno`, אזור: **Frankfurt (eu-central-1)**, ובוחרים סיסמה חזקה למסד הנתונים. **שומרים את הסיסמה.**
3. כשהפרויקט מוכן: **Project Settings → API**. מעתיקים:
   - `Project URL` (נראה כמו `https://abcd1234.supabase.co`)
   - `anon public` key
   - ה-**Reference ID** (החלק `abcd1234` מהכתובת)
4. **Authentication → URL Configuration**:
   - Site URL: כתובת האפליקציה למעלה
   - Redirect URLs: אותה כתובת
5. **Account → Access Tokens** (בפינה למעלה) → **Generate new token**. מעתיקים אותו.

### 2. הפעלת GitHub Pages
במאגר: **Settings → Pages → Source: GitHub Actions**.

### 3. הגדרות במאגר
**Settings → Secrets and variables → Actions**

לשונית **Secrets** (סודי) → New repository secret:
| שם | ערך |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | הטוקן משלב 1.5 |
| `SUPABASE_DB_PASSWORD` | סיסמת מסד הנתונים משלב 1.2 |
| `VAPID_PRIVATE_KEY` | המפתח הפרטי להתראות (נשלח אליך בנפרד – לא לשתף) |

לשונית **Variables** → New repository variable:
| שם | ערך |
|---|---|
| `SUPABASE_URL` | ה-Project URL |
| `SUPABASE_ANON_KEY` | ה-anon public key |
| `SUPABASE_PROJECT_REF` | ה-Reference ID |

### 4. הרצה
**Actions** → מריצים פעם אחת ידנית (**Run workflow**):
1. **Set up Supabase** – יוצר את מסד הנתונים ואת שולח ההתראות.
2. **Publish the app** – מעלה את האפליקציה.

כשכל אחד מהם מסומן ✅ – האפליקציה באוויר.

### 5. כניסה ראשונה של המנהל
1. פותחים את כתובת האפליקציה → **חשבון חדש** → מייל וסיסמה.
2. מאשרים את המייל שמגיע לתיבה, ונכנסים.
3. **מי שנכנס ראשון הופך למנהל.** לכן המנהל (אהרון) צריך להיות הראשון.
4. במסך "הקמה ראשונה" בוחרים **ייבוא קובץ נתונים** ומעלים את `retorno-data-export.json` (נשלח בנפרד). כל המטופלים, ההערות והכספים נכנסים.
5. בוחרים את עצמך מהרשימה ("מי את/ה?").

### 6. הוספת הצוות
1. המנהל: **צוות** → עריכת איש צוות → ממלאים את **המייל** שלו → שמירה.
2. שולחים לו את כתובת האפליקציה. הוא פותח **חשבון חדש** עם אותו מייל – ונכנס ישר לפרופיל שלו.
3. מי שהמייל שלו לא הוכנס ע"י המנהל לא יכול לראות כלום.

## התקנה על הטלפון
- **אנדרואיד (Chrome):** פותחים את הכתובת → תפריט ⋮ → **התקן אפליקציה** / **הוסף למסך הבית**.
- **אייפון (Safari):** פותחים את הכתובת → כפתור השיתוף → **הוסף למסך הבית**. (צריך iOS 16.4 ומעלה, וההתראות עובדות רק מהאייקון במסך הבית.)

### הפעלת התראות
בתוך האפליקציה: **הודעות → הפעלת התראות בטלפון** → מאשרים. עושים את זה בכל מכשיר.

מה מקבל התראה:
- **המנהל** – כל פעם שמשהו מחכה לאישור: הוצאה, פגישה עם מטפל, בקשה, החלפת משמרת.
- **המדריכים** – כל הודעה שהמנהל שולח.

### סוגי הודעות (המנהל בוחר למי לשלוח)
| סוג | נשלח ל |
|---|---|
| ❗ חשובה | כל המדריכים (התראה שנשארת על המסך עד שפותחים) |
| ⭐ מיוחדת | רק המדריכים שהמנהל בוחר |
| 📢 כללית | כל הצוות |

## עדכונים
כל שינוי שנדחף לענף `main` מתפרסם אוטומטית תוך דקה–שתיים. האפליקציה בטלפון מתעדכנת לבד בפתיחה הבאה.

## פרטיות ואבטחה
- כל הנתונים נשמרים ב-Supabase באירופה, וגישה רק למיילים שהמנהל אישר.
- יתרות כספים, תשלומים וסכומי מטפלים – רק המנהל רואה (נאכף במסד הנתונים עצמו, לא רק במסך).
- **אין להעלות למאגר הזה קבצי נתונים של מטופלים** או מפתחות. הקובץ `.gitignore` חוסם את זה.
- מומלץ להפוך את המאגר לפרטי (Settings → General → Change visibility). אם התוכנית שלך ב-GitHub לא מאפשרת Pages במאגר פרטי – הקוד עצמו לא מכיל שום מידע רגיש, כך שגם ציבורי זה בסדר.
